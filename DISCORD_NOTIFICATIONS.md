## 🎯 Обзор системы

Система уведомлений автоматически отправляет сообщения в Discord при важных событиях:

- 💰 **Пополнения баланса** - уведомления о платежах
- 🎮 **Серверы** - создание, удаление, продление
- 👤 **Пользователи** - регистрация, вход, привязка Discord
- 👮 **Админские действия** - изменения в системе
- 🚫 **Баны** - блокировка пользователей
- ⚖️ **Апелляции** - запросы на разбан

### Архитектура

```
Веб-приложение (Next.js)
         ↓
  Discord Webhook API
         ↓
Discord Bot HTTP Server (Express)
         ↓
Discord Channels (Embeds)
```

## ⚙️ Настройка

### 1. Установка зависимостей

```bash
cd discord-bot
npm install express
```

### 2. Настройка переменных окружения

#### Discord Bot `.env`:

```env
# Webhook Server Settings
DISCORD_BOT_WEBHOOK_PORT=3001
INTERNAL_WEBHOOK_SECRET="fluxor-internal-webhook"
```

#### Веб-приложение `.env`:

```env
# Discord Bot Webhook
DISCORD_BOT_WEBHOOK_URL="http://localhost:3001/webhook"
INTERNAL_WEBHOOK_SECRET="fluxor-internal-webhook"
```

**🔐 Важно:** Измените `INTERNAL_WEBHOOK_SECRET` на случайную строку!

```bash
# Генерация секрета
openssl rand -hex 32
```

### 3. Применение миграций базы данных

```bash
npm run db:generate
npm run db:push
```

Это создаст таблицу `DiscordBotSettings` для хранения настроек.

### 4. Запуск бота

```bash
cd discord-bot
node index.js
```

**Вы должны увидеть:**
```
✅ Бот запущен!
🤖 Имя бота: botiks#0793
🌐 Webhook сервер запущен на порту 3001
```

## 📢 Типы уведомлений

### 💰 Пополнения баланса

**Триггер:** Успешный платёж через CrystalPay, YooMoney, Heleket

**Информация:**
- Пользователь (имя, email)
- Сумма пополнения
- Способ оплаты
- Промокод/бонус (если применялся)
- Discord упоминание (если привязан)

**Настройки:**
- Минимальная сумма для уведомления
- Упоминание роли при крупных пополнениях
- Порог "крупного" пополнения

### 🎮 Серверы

**Триггеры:**
- Создание сервера
- Удаление сервера
- Приостановка сервера
- Возобновление сервера
- Продление сервера

**Информация:**
- Название сервера
- Пользователь
- Тарифный план
- Характеристики (RAM, CPU, Диск)
- Дата истечения

### 👤 Пользователи

**Триггеры:**
- Регистрация нового пользователя
- Вход в систему (опционально)
- Подтверждение email
- Привязка Discord

**Информация:**
- Имя пользователя
- Email
- Текущий баланс
- Discord ID (если привязан)

### 👮 Админские действия

**Триггеры:**
- Изменение баланса вручную
- Создание/удаление планов
- Изменение настроек
- Действия с пользователями

**Информация:**
- Тип действия
- Описание
- IP адрес админа
- Timestamp

### 🚫 Баны

**Триггеры:**
- Предупреждение
- Временная блокировка
- Постоянная блокировка
- Разблокировка

**Информация:**
- Пользователь
- Тип бана
- Причина
- Срок (для временных)
- Администратор

### ⚖️ Апелляции

**Триггеры:**
- Создание апелляции
- Одобрение апелляции
- Отклонение апелляции

**Информация:**
- Пользователь
- Статус
- Причина апелляции
- Комментарий админа (если есть)

**Опция:** Упоминание роли при новой апелляции

## 🤖 Команды бота

### `/settings view`

Просмотр текущих настроек уведомлений

**Пример:**
```
/settings view
```

**Доступ:** Только администраторы сервера

### `/settings channel`

Установка канала для определённого типа уведомлений

**Параметры:**
- `type` - Тип канала (log, balance, server, user, admin, appeal)
- `channel` - Текстовый канал

**Примеры:**
```
/settings channel type:balance channel:#💰-пополнения
/settings channel type:log channel:#📋-логи
/settings channel type:appeal channel:#⚖️-апелляции
```

### `/settings toggle`

Включить/выключить тип уведомлений

**Параметры:**
- `type` - Тип уведомлений (balance, server, user, admin, ban, appeal)
- `enabled` - Включено или выключено

**Примеры:**
```
/settings toggle type:balance enabled:True
/settings toggle type:user enabled:False
```

### `/settings minbalance`

Установить минимальную сумму для уведомлений о пополнении

**Параметры:**
- `amount` - Минимальная сумма в рублях

**Примеры:**
```
/settings minbalance amount:100
/settings minbalance amount:0
```

**Примечание:** При значении 0 уведомления будут приходить для любой суммы.

### `/settings mention`

Настройка упоминаний роли

**Параметры:**
- `role` - Роль для упоминания (опционально)
- `large_balance` - Упоминать при крупных пополнениях (опционально)
- `threshold` - Порог крупного пополнения в рублях (опционально)

**Примеры:**
```
/settings mention role:@Модераторы large_balance:True threshold:5000
/settings mention role:@Администраторы
/settings mention large_balance:False
```

## 📝 Настройка каналов

### Рекомендуемая структура каналов

```
📂 ЛОГИ
  ├── 📋 общие-логи         (logChannelId)
  ├── 💰 пополнения         (balanceLogChannelId)
  ├── 🎮 серверы            (serverLogChannelId)
  ├── 👤 пользователи       (userLogChannelId)
  ├── 👮 админ-действия     (adminLogChannelId)
  └── ⚖️ апелляции          (appealChannelId)
```

### Fallback система

Если специальный канал не установлен, уведомление отправляется в общий канал логов.

**Приоритет:**
1. Специальный канал (например, `balanceLogChannelId`)
2. Общий канал логов (`logChannelId`)
3. Не отправляется (если оба не установлены)

### Пример настройки

```bash
# 1. Создайте категорию "ЛОГИ" на вашем Discord сервере

# 2. Создайте текстовые каналы в категории:
#    - 📋-общие-логи
#    - 💰-пополнения
#    - 🎮-серверы
#    - 👤-пользователи
#    - 👮-админ-действия
#    - ⚖️-апелляции

# 3. Настройте права доступа:
#    - Только боты и администраторы могут писать
#    - Модераторы могут читать

# 4. Настройте каналы через команды бота:
/settings channel type:log channel:#📋-общие-логи
/settings channel type:balance channel:#💰-пополнения
/settings channel type:server channel:#🎮-серверы
/settings channel type:user channel:#👤-пользователи
/settings channel type:admin channel:#👮-админ-действия
/settings channel type:appeal channel:#⚖️-апелляции

# 5. Проверьте настройки:
/settings view
```

## 💡 Примеры использования

### Сценарий 1: Базовая настройка

**Цель:** Получать все уведомления в один канал

```
1. Создайте канал #логи
2. /settings channel type:log channel:#логи
3. Готово! Все уведомления будут в одном месте
```

### Сценарий 2: Разделение по типам

**Цель:** Разные каналы для разных типов событий

```
1. Создайте каналы для каждого типа
2. Настройте каждый канал через /settings channel
3. Включите нужные типы через /settings toggle
```

### Сценарий 3: Только важные события

**Цель:** Уведомления только о крупных пополнениях и банах

```
1. /settings toggle type:balance enabled:True
2. /settings toggle type:ban enabled:True
3. /settings toggle type:server enabled:False
4. /settings toggle type:user enabled:False
5. /settings minbalance amount:1000
6. /settings mention role:@Администраторы large_balance:True threshold:5000
```

### Сценарий 4: Тихий режим

**Цель:** Уведомления без упоминаний

```
1. /settings mention large_balance:False
2. Настройте каналы без прав на @everyone и @here
```

### Сценарий 5: Апелляции с упоминанием модераторов

**Цель:** Быстрая реакция на апелляции

```
1. /settings channel type:appeal channel:#⚖️-апелляции
2. /settings mention role:@Модераторы
3. /settings toggle type:appeal enabled:True
```

## 🔧 Решение проблем

### Проблема: Уведомления не приходят

**Проверка:**
1. Бот запущен и webhook сервер работает?
   ```bash
   curl http://localhost:3001/health
   ```

2. Настройки включены?
   ```
   /settings view
   ```

3. Канал установлен?
   ```
   /settings view
   ```

4. Бот имеет права писать в канал?
   - Перейдите в настройки канала
   - Проверьте права бота на "Отправка сообщений"

5. Проверьте логи бота:
   ```bash
   # В терминале где запущен бот
   # Должны быть сообщения:
   📬 Получен webhook: BALANCE
   ```

### Проблема: Webhook сервер не запускается

**Причина:** Порт 3001 занят

**Решение:**
```bash
# Windows
netstat -ano | findstr :3001

# Linux
lsof -i :3001

# Измените порт в .env
DISCORD_BOT_WEBHOOK_PORT=3002
```

### Проблема: Unauthorized при отправке webhook

**Причина:** Неправильный `INTERNAL_WEBHOOK_SECRET`

**Решение:** Убедитесь что секрет одинаковый в обоих `.env` файлах

### Проблема: Упоминания роли не работают

**Причина:** Роль выше роли бота в иерархии

**Решение:**
1. Перейдите в Настройки сервера → Роли
2. Переместите роль бота выше упоминаемой роли

## 🚀 Production рекомендации

### 1. Используйте PM2 для автозапуска

```javascript
// ecosystem.config.js
{
  name: 'fluxor-bot',
  script: 'index.js',
  instances: 1,
  env: {
    NODE_ENV: 'production',
    DISCORD_BOT_WEBHOOK_PORT: 3001
  }
}
```

### 2. Настройте Nginx для HTTPS

Если веб-приложение на другом сервере:

```nginx
# Прокси к боту
location /bot-webhook {
  proxy_pass http://localhost:3001/webhook;
  proxy_set_header Authorization "Bearer your-secret";
}
```

### 3. Мониторинг uptime

- Используйте UptimeRobot для проверки `/health`
- Настройте алерты при падении бота

### 4. Резервное копирование настроек

```bash
# Экспорт настроек из БД
mysqldump -u user -p database DiscordBotSettings > bot-settings-backup.sql
```

### 5. Ротация логов

```bash
# PM2 автоматически делает ротацию
pm2 install pm2-logrotate
pm2 set pm2-logrotate:max_size 10M
pm2 set pm2-logrotate:retain 7
```

## 📚 API Reference

### Webhook Endpoint

**URL:** `POST /webhook`

**Headers:**
```
Content-Type: application/json
Authorization: Bearer {INTERNAL_WEBHOOK_SECRET}
```

**Body:**
```json
{
  "type": "BALANCE" | "SERVER" | "USER" | "ADMIN" | "BAN" | "APPEAL",
  "data": {
    // Специфичные данные для типа
  }
}
```

**Response:**
```json
{
  "success": true
}
```

### Health Check

**URL:** `GET /health`

**Response:**
```json
{
  "status": "ok",
  "bot": "botname#1234",
  "uptime": 12345
}
```
