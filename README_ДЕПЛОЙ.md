## ⚙️ КОНФИГУРАЦИЯ ПЕРЕД ДЕПЛОЕМ

### 1. Проверьте ADMIN_DISCORD_IDS

На VDS должен быть указан ваш Discord ID:

```bash
ssh root@77.91.100.68
cat /var/www/billing/discord-bot/.env | grep ADMIN_DISCORD_IDS
```

**Должно быть:**
```env
ADMIN_DISCORD_IDS="808641359006400512"
```

**Как узнать свой Discord ID:**
1. Discord → Настройки → Расширенные → Режим разработчика (включить)
2. Правый клик на себя → Копировать ID

**Если ID не указан или неправильный:**
```bash
nano /var/www/billing/discord-bot/.env
# Изменить ADMIN_DISCORD_IDS на свой ID
# Ctrl+O → Enter → Ctrl+X
pm2 restart fluxor-bot
```

---

### 2. Проверьте DATABASE_URL (должен быть одинаковым)

```bash
# В боте
cat /var/www/billing/discord-bot/.env | grep DATABASE_URL

# В веб-приложении
cat /var/www/billing/.env | grep DATABASE_URL
```

**Должно быть одинаковым:**
```env
DATABASE_URL="mysql://avelon:123456@localhost:3306/avelon"
```
