## 🆘 Нужна помощь?

### Проблема с иконками мобов?
Иконки загружаются с mc-heads.net. Проверьте интернет-соединение.

### Discord привязка пропадает?
1. Проверьте изменения в `app/api/auth/me/route.ts`
2. Перезапустите сервер
3. Очистите кеш браузера

### 404 на легальных страницах?
1. Убедитесь, что файлы созданы в `app/terms/`, `app/privacy/`, `app/refund/`
2. Перезапустите dev сервер

### Другие проблемы?
Смотрите раздел "Возможные проблемы и решения" в `ПРОВЕРКА_ИЗМЕНЕНИЙ.md`
