## ⚙️ КОНФИГУРАЦИЯ

### 1. Проверить ADMIN_DISCORD_IDS на VDS

```bash
ssh root@77.91.100.68
nano /var/www/billing/discord-bot/.env
```

Убедитесь, что указан ваш Discord ID:
```env
ADMIN_DISCORD_IDS="808641359006400512"
```

Для нескольких админов:
```env
ADMIN_DISCORD_IDS="808641359006400512,123456789012345678"
```

**Как узнать свой Discord ID:**
1. Discord → Настройки → Расширенные → Режим разработчика (включить)
2. Правый клик на себя → Копировать ID

### 2. Проверить NEXT_PUBLIC_APP_URL

```bash
nano /var/www/billing/.env
```

Должно быть:
```env
NEXT_PUBLIC_APP_URL="http://77.91.100.68:3000"
```

### 3. Проверить DATABASE_URL в обоих .env

**Веб-приложение** (`/var/www/billing/.env`):
```env
DATABASE_URL="mysql://avelon:123456@localhost:3306/avelon"
```

**Discord бот** (`/var/www/billing/discord-bot/.env`):
```env
DATABASE_URL="mysql://avelon:123456@localhost:3306/avelon"
```

Они должны совпадать!

**A. Проверка прав:**
```

```

**Ожидается:**
- ✅ Если вы админ: покажет профиль пользователя
- ❌ Если не админ: "Доступ запрещён"

**B. Добавление баланса:**
```
/addbalance user:admin@eqwzzx.wtf amount:100 reason:Тест
```

**Ожидается:**
- ✅ Embed с информацией о начислении
- ✅ Уведомление пользователю в ЛС (если Discord привязан)
- ✅ В базе данных появится запись в `Payment` и `AdminLog`

**C. Просмотр профиля:**
```
/profile user:admin@eqwzzx.wtf
```

**Ожидается:**
- Полная информация о пользователе
- Баланс увеличился на 100 ₽
- В "Последние транзакции" появилась новая запись

### Тест 4: Проверка логики создания серверов

**Сценарий A: Discord привязан**
1. В веб-панели убедитесь, что Discord привязан
2. Попробуйте создать сервер
3. **Ожидается:** Сервер создаётся даже если email не верифицирован

**Сценарий B: Discord не привязан, email не верифицирован**
1. Отвяжите Discord (или создайте нового пользователя)
2. Не верифицируйте email
3. Попробуйте создать сервер
4. **Ожидается:** "Для создания сервера необходимо подтвердить email или привязать Discord"

**Сценарий C: Включена "Обязательная привязка Discord"**
1. Админ-панель → Настройки → Включить "Обязательная привязка Discord"
2. Создайте пользователя без Discord
3. Попробуйте создать сервер
4. **Ожидается:** "Для создания сервера необходимо привязать Discord аккаунт"

## 🐛 ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: "Доступ запрещён" при использовании админских команд

**Причина:** Ваш Discord ID не указан в `ADMIN_DISCORD_IDS`

**Решение:**
```bash
ssh root@77.91.100.68
nano /var/www/billing/discord-bot/.env
```

Добавьте:
```env
ADMIN_DISCORD_IDS="ваш_discord_id"
```

Перезапустите бота:
```bash
pm2 restart fluxor-bot
```

---

### Проблема 2: "Пользователь не найден"

**Причина:** Неправильно указан email или Discord ID не привязан

**Решение:**
- Проверьте правильность написания email
- Убедитесь, что пользователь привязал Discord (для поиска по Discord ID)
- Проверьте в базе данных:
  ```bash
  mysql -u avelon -p avelon
  SELECT id, email, discordId, name FROM User WHERE email = 'user@example.com';
  ```

---

### Проблема 3: Команды не отображаются в Discord

**Причина:** Команды не зарегистрированы

**Решение:**
```bash
ssh root@77.91.100.68
cd /var/www/billing/discord-bot
node deploy-commands.js
```

Подождите 1-5 минут (Discord кэширует команды)

---

### Проблема 4: Ошибка при добавлении/убавлении баланса

**Причина:** Ошибка подключения к базе данных

**Решение:**
1. Проверьте `DATABASE_URL` в `/var/www/billing/discord-bot/.env`
2. Убедитесь, что MySQL работает:
   ```bash
   systemctl status mysql
   ```
3. Проверьте подключение:
   ```bash
   mysql -u avelon -p
   ```
4. Посмотрите логи бота:
   ```bash
   pm2 logs fluxor-bot --lines 50
   ```

---

### Проблема 5: "Для создания сервера необходимо подтвердить email или привязать Discord" (но Discord привязан)

**Причина:** Изменения в `route.ts` не применились

**Решение:**

```bash
# Перезапуск
pm2 restart fluxor-web
```

```sql
-- Последние 10 транзакций
SELECT 
  p.id,
  p.userId,
  u.email,
  p.amount,
  p.method,
  p.description,
  p.status,
  p.createdAt
FROM Payment p
JOIN User u ON p.userId = u.id
ORDER BY p.createdAt DESC
LIMIT 10;
```

### Проверка админских действий

```sql
-- Последние 10 админских действий
SELECT 
  al.id,
  al.userId,
  u.email,
  al.action,
  al.description,
  al.ipAddress,
  al.createdAt
FROM AdminLog al
JOIN User u ON al.userId = u.id
WHERE al.action IN ('BALANCE_ADD', 'BALANCE_REMOVE')
ORDER BY al.createdAt DESC
LIMIT 10;
```

### Проверка балансов пользователей

```sql
-- Топ 10 пользователей по балансу
SELECT 
  id,
  email,
  name,
  balance,
  discordId IS NOT NULL as hasDiscord,
  emailVerified
FROM User
ORDER BY balance DESC
LIMIT 10;
```
