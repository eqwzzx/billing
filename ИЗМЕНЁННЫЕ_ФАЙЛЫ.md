#### 1. `discord-bot/commands/addbalance.js`
**Функция:** Начисление баланса пользователю администратором

**Основные возможности:**
- Поиск пользователя по email или Discord ID
- Обновление баланса в базе данных
- Создание транзакции (таблица `Payment`)
- Логирование действия (таблица `AdminLog`)
- Отправка уведомлений пользователю в ЛС

**Параметры:**
```javascript
/addbalance 
  user: email или Discord ID (обязательно)
  amount: сумма в рублях (обязательно, минимум 0.01)
  reason: причина начисления (опционально)
```

**Пример:**
```
/addbalance user:admin@eqwzzx.wtf amount:500 reason:Компенсация за баг
```

```javascript
const newBalance = Math.max(0, oldBalance - amount);
```

**Параметры:**
```javascript
/removebalance

  reason: причина списания (опционально)
```

**Пример:**
```
/removebalance user:admin@eqwzzx.wtf amount:100 reason:Штраф за нарушение
```

#### 5. `app/api/servers/create/route.ts`
**Что изменилось:**

**БЫЛО (старая логика):**
```javascript
// Только проверка email
if (!user.emailVerified) {
  return NextResponse.json({ 
    error: 'Для создания сервера необходимо подтвердить email.' 
  }, { status: 403 })
}
```

**СТАЛО (новая логика):**
```javascript
// Проверка обязательной привязки Discord
const discordRequiredSetting = await prisma.adminSettings.findUnique({
  where: { key: 'discordRequired' }
})
const discordRequired = discordRequiredSetting?.value === 'true'

// Если Discord привязан, email верификация необязательна
if (!user.discordId && discordRequired) {
  return NextResponse.json({ 
    error: 'Для создания сервера необходимо привязать Discord аккаунт.',
    needsDiscord: true
  }, { status: 403 })
}

// Проверка верификации email только если Discord НЕ привязан
if (!user.discordId && !user.emailVerified) {
  return NextResponse.json({ 
    error: 'Для создания сервера необходимо подтвердить email или привязать Discord. Проверьте почту или обратитесь в поддержку.',
    needsVerification: true
  }, { status: 403 })
}
```

**Новая логика работы:**

| Условие | Результат |
|---------|-----------|
| ✅ Discord привязан | Сервер можно создать (email необязателен) |
| ❌ Discord не привязан + "Обязательная привязка" включена | ⛔ Сервер создать нельзя |
| ❌ Discord не привязан + Email не верифицирован | ⛔ Сервер создать нельзо |
| ✅ Discord не привязан + Email верифицирован | Сервер можно создать |

### Использование Prisma вместо SQL

**В новых командах используется Prisma ORM:**

```javascript
// Поиск пользователя
const user = await db.user.findUnique({
  where: { email: userEmail },
  select: {
    id: true,
    name: true,
    email: true,
    balance: true,
    discordId: true
  }
});

// Обновление баланса
await db.user.update({
  where: { id: user.id },
  data: { balance: newBalance }
});

// Создание транзакции
await db.payment.create({
  data: {
    userId: user.id,
    amount: amount,
    method: 'MANUAL',
    status: 'COMPLETED',
    description: `Начисление администратором: ${reason}`,
    paymentId: `ADMIN_${Date.now()}`
  }
});

// Создание лога
await db.adminLog.create({
  data: {
    userId: user.id,
    action: 'BALANCE_ADD',
    description: `Добавлено ${amount.toFixed(2)} ₽. Причина: ${reason}`,
    ipAddress: 'Discord Bot'
  }
});
```

**Преимущества:**
- ✅ Типизация (TypeScript support)
- ✅ Автоматическая валидация
- ✅ Защита от SQL инъекций
- ✅ Удобный API для запросов
- ✅ Автоматические relations

### Проверка прав администратора

**Все админские команды используют общую проверку:**

```javascript
// Проверка, что пользователь админ в боте
const adminIds = process.env.ADMIN_DISCORD_IDS?.split(',') || [];
if (!adminIds.includes(interaction.user.id)) {
  const embed = new EmbedBuilder()
    .setColor('#ff0000')
    .setTitle('❌ Доступ запрещён')
    .setDescription('Только администраторы могут использовать эту команду.')
    .setTimestamp();

  await interaction.editReply({ embeds: [embed] });
  return;
}
```

**Настройка в .env:**
```env
ADMIN_DISCORD_IDS="808641359006400512,123456789012345678"
```
