### 4. Исправление проблемы с Discord привязкой
**Файл:** `app/api/auth/me/route.ts`

**Проблема:** После перезагрузки биллинга привязка Discord пропадала

**Причина:** В API endpoint `/api/auth/me` не возвращались поля Discord в ответе

**Решение:** Добавлены поля в select запроса:
```typescript
discordId: true,
discordUsername: true,
discordDiscriminator: true,
discordAvatar: true,
discordGlobalName: true,
```

Теперь информация о Discord сохраняется в базе данных и корректно возвращается после перезагрузки.
