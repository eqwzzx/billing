# 🚨 ИСПРАВЛЕНИЕ ОШИБКИ "Invalid or unexpected token" В БОТЕ

## Проблема

```
SyntaxError: Invalid or unexpected token
```

Файлы Discord бота содержат повреждённые символы (null bytes).

---

## ✅ РЕШЕНИЕ

### Вариант 1: Автоматический (PowerShell) - РЕКОМЕНДУЕТСЯ

```powershell
cd C:\Users\Babur\Desktop\Avelon-Web-main
.\Копировать-Бота-На-VDS.ps1
```

Скрипт автоматически:
- Создаст архив с исправными файлами бота
- Скопирует на VDS
- Распакует и установит зависимости
- Перезапустит PM2

### Вариант 2: Через SCP (ручное копирование)

#### На Windows (PowerShell):

```powershell
cd C:\Users\Babur\Desktop\Avelon-Web-main\discord-bot

# Архивируем папку (исключая node_modules)
Compress-Archive -Path *.js,*.json,*.md,commands,handlers,utils,.env.example -DestinationPath ..\discord-bot.zip -Force

cd ..

# Копируем на VDS
scp discord-bot.zip root@77.91.100.68:/tmp/
```

#### На VDS:

```bash
ssh root@77.91.100.68

# Остановить бота
pm2 stop fluxor-bot

# Создать резервную копию
cd /var/www/billing
tar -czf discord-bot-backup-$(date +%Y%m%d).tar.gz discord-bot/

# Удалить старые файлы (кроме .env и node_modules)
cd discord-bot
rm -rf commands handlers utils
rm -f *.js *.md

# Распаковать новые файлы
cd /tmp
unzip -o discord-bot.zip -d /var/www/billing/discord-bot/

# Установить зависимости
cd /var/www/billing/discord-bot
npm install

# Зарегистрировать команды
node deploy-commands.js

# Запустить бота
pm2 restart fluxor-bot

# Проверить логи
pm2 logs fluxor-bot --lines 50
```

## 🔍 ДИАГНОСТИКА

### Найти повреждённый файл

На VDS выполните:

```bash
cd /var/www/billing/discord-bot

# Проверить все .js файлы
for file in *.js commands/*.js handlers/*.js utils/*.js; do
    echo "Checking: $file"
    node --check "$file" 2>&1 | head -1
done
```

Если файл повреждён, вы увидите:
```
Checking: commands/help.js
SyntaxError: Invalid or unexpected token
```

### Проверить наличие null bytes

```bash
# Проверить конкретный файл
hexdump -C commands/help.js | grep "00 00 00"

# Если видите много нулей (00) - файл повреждён
```

## 🆘 ЕСЛИ ОШИБКА ОСТАЁТСЯ

### 1. Проверьте версию Node.js

```bash
node --version
```

Требуется Node.js 18+ для ES modules.

### 2. Проверьте package.json

```bash
cat discord-bot/package.json | grep "type"
```

Должно быть:
```json
"type": "module"
```

### 3. Проверьте .env файл

```bash
cat discord-bot/.env
```

Убедитесь, что:
- `DISCORD_TOKEN` установлен
- `DATABASE_URL` правильный
- Нет лишних символов
