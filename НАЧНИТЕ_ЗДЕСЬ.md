## 🔄 ТИПИЧНЫЕ СЦЕНАРИИ

### Первое развёртывание на VDS

1. `PRODUCTION_DEPLOY.md` - следуйте инструкции по развёртыванию
2. `СРОЧНОЕ_ИСПРАВЛЕНИЕ.md` - исправьте синтаксические ошибки
3. `РЕШЕНИЕ_ПРОБЛЕМЫ_401.md` - исправьте проблему с авторизацией
4. `DISCORD_NOTIFICATIONS.md` - настройте Discord бота

### Локальная разработка

1. `ЗАПУСК_ПРОЕКТА.md` - установка и запуск
2. `MARIADB_GUIDE.md` - если используете MariaDB
3. `discord-bot/СТАРТ.md` - запуск Discord бота

### Обновление на production

1. Скопируйте файлы на VDS (через git, scp или `Копировать-На-VDS.ps1`)
2. Выполните на VDS:
   ```bash
   cd /var/www/billing
   rm -rf .next
   npm run build
   pm2 restart fluxor-web
   pm2 logs fluxor-web
   ```
3. Проверьте работу в браузере

### Проблемы с авторизацией

1. `РЕШЕНИЕ_ПРОБЛЕМЫ_401.md` - диагностика и решение
2. Или используйте `.\Копировать-На-VDS.ps1` для автоматического исправления
3. Проверьте логи: `pm2 logs fluxor-web`

## 💡 СОВЕТЫ

### Режим инкогнито
Всегда тестируйте авторизацию в режиме инкогнито (`Ctrl+Shift+N`), чтобы не было старых cookies.

### Проверка логов
Следите за логами в реальном времени:
```bash
pm2 logs fluxor-web
```

### Резервные копии
Перед изменениями создавайте резервные копии:
```bash
cp file.ts file.ts.backup
```

### Сборка после изменений
Всегда пересобирайте после изменения кода:
```bash
rm -rf .next && npm run build
```
