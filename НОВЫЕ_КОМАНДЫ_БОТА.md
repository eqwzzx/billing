## 📚 ПОДРОБНОЕ ОПИСАНИЕ

### 1. `/addbalance` - Добавление баланса

**Описание:** Начисляет баланс пользователю и создаёт запись о транзакции.

**Параметры:**
- `user` (обязательный) - Email или Discord ID пользователя
- `amount` (обязательный) - Сумма для начисления (минимум 0.01)
- `reason` (опционально) - Причина начисления

**Примеры:**
```
/addbalance user:admin@example.com amount:500 reason:Компенсация за баг
/addbalance user:123456789012345678 amount:100
/addbalance user:user@domain.com amount:1000 reason:Акция
```

**Что происходит:**
1. Проверка прав администратора
2. Поиск пользователя по email или Discord ID
3. Обновление баланса в базе данных
4. Создание записи транзакции (`Payment`)
5. Создание записи в логах админа (`AdminLog`)
6. Отправка уведомления пользователю (если Discord привязан)

**Результат:**
- Embed с информацией о начислении
- Старый и новый баланс
- Уведомление пользователю в личные сообщения

---

### 2. `/removebalance` - Убавление баланса

**Описание:** Списывает баланс у пользователя. Баланс не может стать отрицательным.

**Параметры:**
- `user` (обязательный) - Email или Discord ID пользователя
- `amount` (обязательный) - Сумма для списания (минимум 0.01)
- `reason` (опционально) - Причина списания

**Примеры:**
```
/removebalance user:admin@example.com amount:50 reason:Штраф за нарушение правил
/removebalance user:123456789012345678 amount:100
```

**Особенности:**
- Если сумма списания больше текущего баланса, спишется только доступная сумма
- Баланс никогда не уходит в минус
- В embed показывается фактически списанная сумма

**Что происходит:**
1. Проверка прав администратора
2. Поиск пользователя
3. Расчёт фактически списываемой суммы (`Math.max(0, balance - amount)`)
4. Обновление баланса
5. Создание транзакции с отрицательной суммой
6. Логирование действия
7. Уведомление пользователю

---

### 3. `/profile` - Просмотр профиля

**Описание:** Показывает полную информацию о пользователе.

**Параметры:**
- `user` (обязательный) - Email или Discord ID пользователя

**Примеры:**
```
/profile user:admin@example.com
/profile user:123456789012345678
```

**Показываемая информация:**
- 📧 Email
- 📝 Имя
- 🎭 Роль (USER/ADMIN/MODERATOR)
- 💰 Текущий баланс
- 🎮 Количество активных серверов
- 📊 Всего серверов за всё время
- ✅ Статус верификации email
- 🔗 Статус привязки Discord
- 🔒 Информация о бане (если есть)
- 💳 Количество транзакций
- 🆔 Pterodactyl ID
- 📅 Дата регистрации
- 💳 Последние 5 транзакций

**Дополнительно:**
- Если у пользователя есть Discord аватар, он отображается
- Если пользователь забанен, показывается детальная информация о бане
- Используются Discord timestamps для красивого отображения дат

## 🔐 ПРАВА ДОСТУПА

### Проверка прав администратора

Команды `/addbalance`, `/removebalance` и `/profile` требуют:

1. **Discord серверные права:** `Administrator`
2. **Discord ID в переменной окружения:** `ADMIN_DISCORD_IDS`

Как добавить админа в `.env`:

```bash
# Для одного админа
ADMIN_DISCORD_IDS="123456789012345678"

# Для нескольких админов (через запятую)
ADMIN_DISCORD_IDS="123456789012345678,987654321098765432"
```

**Как узнать свой Discord ID:**
1. Включите режим разработчика в Discord (Настройки → Расширенные → Режим разработчика)
2. Правый клик на своём имени → Копировать ID

### Ошибка: "Доступ запрещён"

**Причина:** Ваш Discord ID не добавлен в `ADMIN_DISCORD_IDS`

**Решение:**
```bash
ssh root@77.91.100.68
nano /var/www/billing/discord-bot/.env
```

Добавьте:
```
ADMIN_DISCORD_IDS="ваш_discord_id"
```

Перезапустите бота:
```bash
pm2 restart fluxor-bot
```

### Ошибка: "Пользователь не найден"

**Причина:** Неправильно указан email или Discord ID

**Решение:**
- Проверьте правильность написания email
- Для Discord ID убедитесь, что у пользователя привязан Discord
- Используйте команду `/profile` для проверки

### Ошибка: "Команда не найдена"

**Причина:** Команды не зарегистрированы

**Решение:**
```bash
cd /var/www/billing/discord-bot
```

## 📊 БАЗА ДАННЫХ

### Таблицы, которые обновляются:

**User** - обновляется поле `balance`
```sql
SELECT id, email, balance FROM User WHERE email = 'user@example.com';
```

**Payment** - создаётся новая запись
```sql
SELECT * FROM Payment WHERE userId = 'user_id' ORDER BY createdAt DESC LIMIT 5;
```

**AdminLog** - логируется действие администратора
```sql
SELECT * FROM AdminLog WHERE action IN ('BALANCE_ADD', 'BALANCE_REMOVE') ORDER BY createdAt DESC;
```

## 📚 ДОПОЛНИТЕЛЬНО

### Интеграция с уведомлениями

Команды автоматически отправляют уведомления пользователям через Discord ЛС, если:
- У пользователя привязан Discord (`discordId` не null)
- Бот может отправить личное сообщение пользователю

### Логирование

Все действия администратора логируются в таблицу `AdminLog`:
- Кто выполнил действие
- Какое действие (BALANCE_ADD / BALANCE_REMOVE)
- Описание (сумма и причина)
- IP адрес: "Discord Bot"
