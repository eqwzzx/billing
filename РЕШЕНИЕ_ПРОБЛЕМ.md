## 🤖 ПРОБЛЕМЫ С DISCORD БОТОМ

### ❌ Бот не отвечает на команды

**Симптомы:**
- Команды не работают
- Бот показывает "offline" в Discord

**Диагностика:**
```bash
ssh root@77.91.100.68
pm2 status
```

**Решение 1: Бот не запущен**
```bash
cd /var/www/billing
pm2 start ecosystem.config.js --only fluxor-bot
```

**Решение 2: Бот упал с ошибкой**
```bash
# Посмотреть логи
pm2 logs fluxor-bot --lines 50

# Перезапустить
pm2 restart fluxor-bot

# Если не помогает, убить и запустить заново
pm2 delete fluxor-bot
cd discord-bot
pm2 start index.js --name fluxor-bot
```

**Решение 3: Проблема с токеном**
```bash
# Проверить токен
cat /var/www/billing/discord-bot/.env | grep DISCORD_TOKEN

# Если токен неправильный, исправить
nano /var/www/billing/discord-bot/.env
```

Перезапустить бота после исправления:
```bash
pm2 restart fluxor-bot
```

### ❌ Доступ запрещён (админские команды)

**Симптомы:**
- При использовании `/addbalance`, `/removebalance`, `/profile`
- Ошибка: "❌ Доступ запрещён"

**Причина:**
Ваш Discord ID не указан в `ADMIN_DISCORD_IDS`

**Решение:**

**1. Узнать свой Discord ID:**
- Discord → Настройки → Расширенные → Режим разработчика (включить)
- Правый клик на себя → Копировать ID
- Например: `808641359006400512`

**2. Добавить в .env:**
```bash
ssh root@77.91.100.68
nano /var/www/billing/discord-bot/.env
```

Найти строку:
```env
ADMIN_DISCORD_IDS=808641359006400512
```

Изменить на свой ID или добавить несколько через запятую:
```env
ADMIN_DISCORD_IDS="808641359006400512,123456789012345678"
```

**3. Сохранить и перезапустить:**
```bash
# Ctrl+O → Enter → Ctrl+X
pm2 restart fluxor-bot
```

**4. Проверить:**
```
/profile user:admin@eqwzzx.wtf
```

Должно показать профиль без ошибки.

### ❌ Пользователь не найден

**Симптомы:**
- При использовании `/addbalance`, `/profile` и т.д.
- Ошибка: "❌ Пользователь не найден"

**Причина 1: Неправильно указан email**

**Решение:**
Проверьте правильность написания:
```sql
mysql -u avelon -p avelon
SELECT id, email, name FROM User WHERE email LIKE '%admin%';
```

**Причина 2: Ищете по Discord ID, но он не привязан**

**Решение:**
```sql
SELECT id, email, discordId FROM User WHERE email = 'user@example.com';
```

Если `discordId` = NULL, пользователь не привязал Discord.

Используйте email вместо Discord ID:
```
/profile user:user@example.com
```

**Причина 3: Пользователь действительно не существует**

**Решение:**
Проверьте в базе данных:
```sql
SELECT COUNT(*) FROM User WHERE email = 'user@example.com';
```

Если вернуло `0`, пользователя нет. Создайте через регистрацию на сайте.

## 💰 ПРОБЛЕМЫ С БАЛАНСОМ

### ❌ Баланс не обновляется после /addbalance

**Симптомы:**
- Команда выполнилась успешно
- Embed показывает новый баланс
- Но в веб-панели баланс старый

**Причина:**
Кэширование или не обновилась страница

**Решение:**
```bash
# 1. Проверить в базе данных
mysql -u avelon -p avelon
SELECT id, email, balance FROM User WHERE email = 'user@example.com';
```

Если в базе баланс обновился:
- Обновите страницу (Ctrl+F5)
- Очистите кэш браузера

Если в базе баланс НЕ обновился:
```bash
# Проверить логи бота
pm2 logs fluxor-bot --lines 100 | grep "Error adding balance"
```

### ❌ Баланс уходит в минус

**Симптомы:**
- После `/removebalance` баланс отрицательный

**Причина:**
Это невозможно. В коде есть защита:
```javascript
const newBalance = Math.max(0, oldBalance - amount);
```

**Если всё же случилось:**
```bash
# Проверить версию файла
ssh root@77.91.100.68
cat /var/www/billing/discord-bot/commands/removebalance.js | grep "Math.max"
```

Должно быть:
```javascript
const newBalance = Math.max(0, oldBalance - amount);
```

Если этой строки нет, скопируйте обновлённый файл:
```bash
scp discord-bot\commands\removebalance.js root@77.91.100.68:/var/www/billing/discord-bot/commands/
ssh root@77.91.100.68
pm2 restart fluxor-bot
```

**Исправить отрицательный баланс вручную:**
```sql
mysql -u avelon -p avelon
UPDATE User SET balance = 0 WHERE balance < 0;
```

3. Попробуйте создать сервер

### ❌ Ошибка "Для создания сервера необходимо привязать Discord аккаунт"

**Симптомы:**
- Включена "Обязательная привязка Discord"
- У пользователя Discord не привязан
- Email верифицирован, но всё равно ошибка

**Причина:**
Это правильное поведение! Если включена "Обязательная привязка Discord", создать сервер БЕЗ Discord нельзя.

**Решение:**

**Вариант 1: Привязать Discord**
```
В веб-панели → Настройки профиля → Привязать Discord
```

**Вариант 2: Отключить "Обязательную привязку"**
```
Админ-панель → Настройки → Убрать галочку "Обязательная привязка Discord"
```

**Проверка настройки на VDS:**
```sql
mysql -u avelon -p avelon
SELECT * FROM AdminSettings WHERE `key` = 'discordRequired';
```

Если `value` = `'true'`, значит привязка обязательна.

## 🗄️ ПРОБЛЕМЫ С БАЗОЙ ДАННЫХ

### ❌ Error: getaddrinfo ENOTFOUND localhost

**Симптомы:**
- Команды бота не работают
- Ошибка подключения к базе данных

**Причина:**
Неправильный `DATABASE_URL` в `.env`

**Решение:**
```bash
ssh root@77.91.100.68

# Проверить DATABASE_URL в боте
cat /var/www/billing/discord-bot/.env | grep DATABASE_URL

# Проверить DATABASE_URL в веб-приложении
cat /var/www/billing/.env | grep DATABASE_URL
```

Оба должны быть одинаковыми:
```env
DATABASE_URL="mysql://avelon:123456@localhost:3306/avelon"
```

Если не совпадают, исправить:
```bash
nano /var/www/billing/discord-bot/.env
```

Перезапустить:
```bash
pm2 restart fluxor-bot
```

### ❌ Access denied for user 'avelon'@'localhost'

**Симптомы:**
- Ошибка доступа к базе данных
- Неправильный пароль

**Решение:**
```bash
# Проверить пароль
mysql -u avelon -p

# Если не подходит, сбросить пароль
mysql -u root -p

ALTER USER 'avelon'@'localhost' IDENTIFIED BY '123456';
FLUSH PRIVILEGES;
EXIT;

# Обновить в .env
nano /var/www/billing/.env
nano /var/www/billing/discord-bot/.env

# Изменить на:
DATABASE_URL="mysql://avelon:123456@localhost:3306/avelon"

# Перезапустить
pm2 restart all
```

**Симптомы:**
- При запуске скрипта ошибка `scp: command not found`

**Причина:**
OpenSSH не установлен или не в PATH

**Решение 1: Установить OpenSSH**
```powershell
# Windows 10/11
Settings → Apps → Optional Features → Add a feature → OpenSSH Client
```

**Решение 2: Использовать Git Bash**
```bash
cd /c/Users/Babur/Desktop/Avelon-Web-main

# Скопировать файлы через Git Bash
scp discord-bot/commands/*.js root@77.91.100.68:/var/www/billing/discord-bot/commands/
```

**Решение 3: Использовать WinSCP**
1. Скачать WinSCP
2. Подключиться к 77.91.100.68
3. Скопировать файлы вручную

### ❌ Permission denied (publickey)

**Симптомы:**
- При подключении по SSH ошибка доступа

**Решение:**

**Вариант 1: Использовать пароль**
```bash
ssh -o PreferredAuthentications=password root@77.91.100.68
```

**Вариант 2: Настроить SSH ключ**
```powershell
# Генерировать ключ (если нет)
ssh-keygen -t rsa -b 4096

# Скопировать ключ на VDS
type $env:USERPROFILE\.ssh\id_rsa.pub | ssh root@77.91.100.68 "cat >> ~/.ssh/authorized_keys"
```
