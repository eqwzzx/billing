# 🔐 РЕШЕНИЕ ПРОБЛЕМЫ 401 UNAUTHORIZED

## 🎯 Описание проблемы

**Симптомы:**
- ✅ Логин успешен (видно `LOGIN_SUCCESS` в логах PM2)
- ❌ `/api/auth/me` возвращает 401 Unauthorized
- ❌ После логина пользователь не авторизован
- ❌ В браузере cookie `auth-token` отсутствует

**Причина:**
Cookie устанавливается с флагом `secure: true` (требует HTTPS), но сайт работает на HTTP.
Браузер **отклоняет** такие cookies из соображений безопасности.

## 🔍 ЧТО БЫЛО ИЗМЕНЕНО

### Файл: `app/api/auth/login/route.ts`

**БЫЛО (строка ~107):**
```typescript
response.cookies.set('auth-token', token, {
  httpOnly: true,
  secure: process.env.NODE_ENV === 'production',  // ← проблема здесь
  sameSite: 'lax',
  maxAge: 60 * 60 * 24 * 7,
  path: '/'
})
```

**СТАЛО:**
```typescript
response.cookies.set('auth-token', token, {
  httpOnly: true,
  secure: false,  // ИЗМЕНИТЬ НА true ПОСЛЕ НАСТРОЙКИ SSL/HTTPS!
  sameSite: 'lax',
  maxAge: 60 * 60 * 24 * 7,
  path: '/'
})
```

### Файл: `app/api/auth/me/route.ts`

- Добавлены debug логи для отслеживания cookies
- Временно отключена проверка `isAuthEnabled()` (проблема с БД)

## ⚠️ ВАЖНО: ПОСЛЕ НАСТРОЙКИ SSL

Когда настроите HTTPS (Let's Encrypt, см. `PRODUCTION_DEPLOY.md`), **обязательно** верните:

```typescript
secure: false,  // ← ИЗМЕНИТЬ
```

На:

```typescript
secure: true,   // ← Для HTTPS
```

Это необходимо для безопасности!
