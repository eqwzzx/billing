```

**Исправьте файл `app/api/auth/me/route.ts`:**

```

Найдите строки (6-9):
```typescript
const JWT_SECRET = process.env.JWT_SECRET
if (!JWT_SECRET) {
  throw new Error('JWT_SECRET environment variable is required')
}
```

Замените на:
```typescript
const JWT_SECRET = process.env.JWT_SECRET

export async function GET(request: NextRequest) {
  console.log('=== /api/auth/me DEBUG ===')
  console.log('All cookies:', request.cookies.getAll())
  console.log('Cookie header:', request.headers.get('cookie'))
  console.log('JWT_SECRET exists:', !!JWT_SECRET)
  
  if (!JWT_SECRET) {
    console.error('❌ JWT_SECRET not configured')
    return NextResponse.json({ error: 'Server configuration error' }, { status: 500 })
  }
```

**ВАЖНО:** Проверка JWT_SECRET должна быть **внутри** функции GET, а не снаружи!

## 🔍 Что было исправлено?

### Файл: `app/api/auth/me/route.ts`

**БЫЛО (неправильно):**
```typescript
const JWT_SECRET = process.env.JWT_SECRET
if (!JWT_SECRET) {
  throw new Error('JWT_SECRET environment variable is required')  // ← ВНЕ ФУНКЦИИ!
}

export async function GET(request: NextRequest) {
  // ...
}
```

**СТАЛО (правильно):**
```typescript
const JWT_SECRET = process.env.JWT_SECRET

export async function GET(request: NextRequest) {
  console.log('=== /api/auth/me DEBUG ===')
  // ...
  
  if (!JWT_SECRET) {  // ← ВНУТРИ ФУНКЦИИ!
    console.error('❌ JWT_SECRET not configured')
    return NextResponse.json({ error: 'Server configuration error' }, { status: 500 })
  }
  
  // ...
}
```

### Причина ошибки

В TypeScript/JavaScript **нельзя** использовать `throw` или `return` на верхнем уровне модуля (вне функции).
