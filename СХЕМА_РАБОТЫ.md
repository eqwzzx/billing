## 🎮 ЛОГИКА СОЗДАНИЯ СЕРВЕРОВ

### СТАРАЯ ЛОГИКА (до изменений):
```
Пользователь создаёт сервер
         │
         ▼
Email верифицирован? ─── ❌ ─→ "Подтвердите email"
         │
         ✅
         ▼
Сервер создан ✅
```

### НОВАЯ ЛОГИКА (после изменений):
```
Пользователь создаёт сервер
         │
         ▼
┌─────────────────────────┐
│ Discord привязан?       │
└─────────────────────────┘
    ├─── ✅ Да ────────────────────────┐
    │                                   │
    └─── ❌ Нет                         │
         │                              │
         ▼                              │
┌─────────────────────────┐            │
│ "Обязательная привязка" │            │
│ включена?               │            │
└─────────────────────────┘            │
    ├─── ✅ Да ────────────┐           │
    │                       │           │
    └─── ❌ Нет            │           │
         │                  │           │
         ▼                  │           │
┌─────────────────────────┐│           │
│ Email верифицирован?    ││           │
└─────────────────────────┘│           │
    ├─── ✅ Да ────────────┼───────────┤
    │                       │           │
    └─── ❌ Нет            │           │
         │                  │           │
         ▼                  ▼           ▼
   ⛔ Ошибка:         ⛔ Ошибка:   ✅ Сервер
   "Подтвердите      "Привяжите   создан
   email или          Discord"
   привяжите
   Discord"
```

**Простыми словами:**
1. **Discord привязан** → ✅ Можно создать сервер (email необязателен)
2. **Discord не привязан + "Обязательная привязка" включена** → ⛔ Нельзя создать
3. **Discord не привязан + Email верифицирован** → ✅ Можно создать
4. **Discord не привязан + Email не верифицирован** → ⛔ Нельзя создать

```

         │
         ▼
┌────────────────────────────────────┐
│ Проверка в переменной окружения:  │
│ ADMIN_DISCORD_IDS                 │
└────────────────────────────────────┘
         │
         ├─── Discord ID есть в списке? ──── ✅ Да ──→ Разрешить
         │
         └─── Discord ID нет в списке? ──── ❌ Нет ──→ "Доступ запрещён"
```

**Пример конфигурации:**
```env
# Один админ
ADMIN_DISCORD_IDS="808641359006400512"

# Несколько админов
ADMIN_DISCORD_IDS="808641359006400512,123456789012345678,999888777666555444"
```
